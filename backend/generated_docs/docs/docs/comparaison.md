

# Comparaison des architectures


Architecture détectée :

**Next.js Application**


## MVC

Séparation :
Model / View / Controller.


Avantages :

- Organisation claire
- Très utilisée


## Layered Architecture

Séparation :

Controller
Service
Repository


Avantages :

- Bonne maintenabilité
- Facile à tester


## Clean Architecture

Séparation du métier de la technique.


Avantages :

- Très évolutive
