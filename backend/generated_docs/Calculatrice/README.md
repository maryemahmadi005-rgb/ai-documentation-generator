# Calculatrice

## Description
La calculatrice est une application Java simple qui permet à l'utilisateur de réaliser des opérations arithmétiques. Elle propose un interface utilisateur intuitive pour effectuer des calculs avec précision.

## Features
- Effectuer des opérations arithmétiques (addition, soustraction, multiplication, division)
- Afficher le résultat du calcul sur l'écran
- Utiliser un système de boutons pour entrer les chiffres et les opérateurs

## Technologies Used
- Java
- javax

## Prerequisites
- Java installed sur le système d'exploitation
- Aucune autre dépendance requise
