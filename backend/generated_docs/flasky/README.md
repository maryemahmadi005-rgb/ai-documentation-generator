# flasky

## Description
Flasky est une application web Python qui utilise Flask pour créer des API RESTful. Elle permet aux développeurs d'automatiser les tâches répétitives et de gérer efficacement leurs projets.

## Features
- Création d'API RESTful avec Flask
- Gestion de données en base de données SQLite
- Automatisation de tâches répétitives avec des scripts Python
- Utilisation de la bibliothèque `requests` pour les requêtes HTTP

## Technologies Used
- Flask : rôle principal
- Python : langage de programmation
- SQLite : base de données
- Requests : bibliothèque pour les requêtes HTTP

## Prerequisites
- Python 3.8 ou supérieur
- Flask installé via pip (`pip install flask`)

## Installation
- `pip install flask`
- `python -m flasky`

## Usage
- Exécution de l'application avec `python -m flasky`
- Accès à la documentation de l'API en visitant `http://localhost:5000/docs`
