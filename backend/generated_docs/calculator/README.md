# calculator

## Description
A simple Node.js application that exposes REST APIs for arithmetic operations on integers, providing a basic pocket calculator experience.

## Features
- Performs addition, subtraction, multiplication, and division operations
- Returns results in JSON format
- Includes a test suite with Mocha and Chai for unit testing
- Generates XML output using Mocha-JUnit-Reporter

## Technologies Used
Docker, Express.js, JavaScript, Node.js

## Prerequisites
- Node.js installed (version 14 or higher)
- Docker installed (version 20.10 or higher)

## Installation
1. Clone the repository: `git clone https://github.com/your-repo/calculator.git`
2. Run `npm install` to install dependencies
3. Run `docker-compose up -d` to start the container

## Usage
Run `npm test` to execute unit tests and generate XML output.
Use `curl` or a REST client to interact with the calculator API.

## Project Structure
A basic Node.js application with Express.js routes and a test suite using Mocha.
