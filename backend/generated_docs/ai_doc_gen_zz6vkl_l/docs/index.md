# ai_doc_gen_zz6vkl_l

Le fichier `Main` est un programme JavaFX qui simule une calculatrice simple. Voici les informations clés sur son rôle :

**Objectif principal** : Le but de ce programme est de créer une interface utilisateur pour une calculatrice numérique, permettant à l'utilisateur d'entrer des expressions mathématiques et de les évaluer.

**Classes/fonctions importantes** :

* La classe `Main` qui étend la classe `Application` de JavaFX. Elle contient le code principal du programme.
* Les classes `TextField`, `Button` et `GridPane` de JavaFX, utilisées pour créer l'interface utilisateur.
* Les méthodes `start` et `setOnAction` qui définissent les actions à effectuer lorsque les boutons sont cliqués.

**Dépendances** : Ce programme nécessite la bibliothèque JavaFX pour fonctionner. Il utilise également les classes de base de Java, telles que `String`, `Integer` et `Exception`.
