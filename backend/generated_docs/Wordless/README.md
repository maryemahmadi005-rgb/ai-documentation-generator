# Wordless

## Description
Wordless est une application intégrée pour l'étude du langage, offrant un support multilingue. Le projet semble être centré sur la gestion de corpus linguistiques.

## Features
- Gestion de corpus linguistiques
- Support multilingue
- Analyse et traitement de textes

## Technologies Used
- **Python** : rôle principal, fichier `wl_main.py`
- **TypeScript** : rôle secondaire, fichier `wl_ngram_generator.py`
- **PIL** : utilisation dans les imports, fichier `wordless/wl_settings/wl_settings_dependency_parsing.py`
- **PyQt5** : utilisation dans les imports, fichier `wordless/wl_settings/wl_settings_dependency_parsing.py`
- **SQLite** : base de données utilisée, fichier non spécifié
