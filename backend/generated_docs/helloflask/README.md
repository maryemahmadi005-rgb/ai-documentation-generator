# helloflask

## Description
Le projet HelloFlask est une application Flask qui permet de créer des applications web interactives. Il contient divers exemples d'applications, notamment des pages statiques, des formulaires, des bases de données et des API.

## Features
- Exemples d'applications statiques
- Formulaire pour saisir un nom
- Base de données pour stocker les notes
- API pour partager les notes

## Technologies Used
- Python : rôle principal, fichier app.py
- Flask : framework web, fichier app.py
- PostgreSQL : base de données, fichier demos/database/app.py
- MkDocs : générateur de documentation, fichier README.md
- Pipenv : gestion des dépendances, fichier requirements.txt

## Prerequisites
- Python 3.8 ou supérieur
- pipenv install

## Installation
1. Créez un nouveau projet avec pipenv install
2. Configurez les variables d'environnement dans le fichier .env
3. Lancez l'application avec python app.py
