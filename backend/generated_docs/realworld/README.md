# realworld

## Description
This is a SvelteKit fullstack application built with Node.js, TypeScript, and Vite. It demonstrates CRUD operations, authentication, routing, pagination, and more, adhering to the RealWorld spec and API.

## Features
- CRUD (Create, Read, Update, Delete) operations for users and posts.
- Authentication using a token-based system.
- Routing with client-side routing enabled.
- Pagination for listing posts.

## Technologies Used
JavaScript, Node.js, TypeScript, Vite

## Prerequisites
- Node.js 16 or higher installed on your machine.
- npm or yarn package manager installed.

## Installation
```sh
pnpm install
pnpm run dev
```

To build and start in prod mode:

```sh
pnpm run build
pnpm run preview
```

## Usage
Run `pnpm run dev` to start the development server. Open your browser at <http://localhost:3000> to access the application.

## Project Structure
This is a SvelteKit project with a standard directory structure, including `$lib`, `pages`, and `src`.
