# flask

## Description
Flask is a lightweight [WSGI] web application framework designed to make getting started quick and easy, with the ability to scale up to complex applications.

## Features
- Provides a flexible way to build web applications
- Supports multiple databases and caching systems
- Includes tools for testing and debugging

## Technologies Used
- Python 3.7+
- Werkzeug
- Jinja2
- WSGI

## Prerequisites
- Python 3.7+ installed
- pip (Python package manager) installed

## Installation
```bash
pip install flask
```

## Usage
```bash
python app.py
```
