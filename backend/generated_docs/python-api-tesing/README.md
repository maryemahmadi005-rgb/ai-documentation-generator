# python-api-tesing

## Description
Le projet `python-api-tesing` semble être un ensemble de bibliothèques et de scripts pour les tests de développement de Python. Il contient des outils pour la gestion des tâches, la reconnaissance faciale et l'analyse de données.

## Features
- Gestion des tâches via MongoDB
- Reconnaissance faciale avec `check_face.py`
- Analyse de données avec `get_gaze_value.py` et `get_live_server_result.py`

## Technologies Used
- Python : rôle principal, fichier concerné
- Flask : point d'entrée pour l'API, fichier concerné
- MySQL : gestion des bases de données, fichier concerné
- MongoDB : stockage des données de tests, fichier concerné

## Prerequisites
- Python 3.x
- Bibliothèque Flask installée

## Installation
1. Installez les dépendances avec `pip install -r requirements.txt`
2. Configurez la base de données MySQL ou MongoDB selon vos besoins.

## Usage
1. Lancez l'API avec `python app.py`
2. Utilisez les points d'entrée pour exécuter des tâches spécifiques, comme `flask/api_demo/app.py`
