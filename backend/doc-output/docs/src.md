# src/

Le rôle général du dossier "src" est de contenir le code source principal du projet, notamment la classe d'entrée principale `Main.java` qui démarre l'exécution de l'applicatif. Ce dossier fournit également les fichiers de classes et méthodes nécessaires pour démarrer le programme et les opérations souhaitées.

## `Main.java`

Le fichier `Main.java` est la classe d'entrée principale du projet, c'est-à-dire le point d'où commence l'exécution de l'application. Son objectif est donc de démarrer l'applicatif et de déclencher les opérations souhaitées.

Les fonctions/classes importantes dans ce fichier sont probablement la méthode `main(String[] args)` qui est la méthode d'entrée de l'application, ainsi que d'autres méthodes ou classes qui sont nécessaires pour démarrer le programme. Ces éléments peuvent inclure des imports de bibliothèques externes ou des appels à des classes ou méthodes définies dans d'autres fichiers du projet.

Les dépendances principales du fichier `Main.java` sont les bibliothèques ou frameworks utilisés par l'applicatif, ainsi que les autres classes ou fichiers du projet qui sont importés et appelés à partir de ce fichier.
