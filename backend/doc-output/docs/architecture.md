# Analyse de l'architecture

Analyse automatique des rôles des dossiers.

## `src/`

Le rôle général du dossier "src" est de contenir le code source principal du projet, notamment la classe d'entrée principale `Main.java` qui démarre l'exécution de l'applicatif. Ce dossier fournit également les fichiers de classes et méthodes nécessaires pour démarrer le programme et les opérations souhaitées.
