# UMI Falsk API

API de détection d'informations sur des documents générés par UMI Falsk

## Features

- Détection d'informations sur des documents générés par UMI Falsk
- Analyse de la structure des documents
- Recherche de liens vers des ressources externes

## Installation

[
  "cd front2 && npm install",
  "npm install",
  "pip install -r backend/requirements.txt"
]

## Usage

[
  "cd front2 && npm run build",
  "cd front2 && npm run dev",
  "npm run build",
  "npm run dev"
]
