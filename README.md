# Analyse du projet

Analyse du projet basée sur les données fournies.

## Features

- Un système de gestion de projet avec des fonctionnalités de gestion de versions
- Une interface utilisateur web pour la gestion du projet

## Installation

[
  "cd front2 && npm install",
  "cd frontend && npm install",
  "npm install"
]

## Usage

[
  "cd front2 && npm run build",
  "cd front2 && npm run dev",
  "cd frontend && npm run build",
  "cd frontend && npm run dev",
  "npm run build",
  "npm run dev"
]
